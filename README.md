
# Flask and MongoDB Assignment

## Objective
Build a Flask application with a JSON API route and a frontend form that stores submitted data in MongoDB Atlas.

## Technologies Used
- Python
- Flask
- MongoDB Atlas
- PyMongo
- HTML
- JSON

## Project Features
1. JSON API using /api route.
2. Reads data from data.json.
3. Frontend student registration form.
4. Stores submitted information in MongoDB Atlas.
5. Redirects to success page after successful submission.
6. Displays errors on the same page.

## Installation

1. Install Python.
2. Install required packages:

pip install -r requirements.txt

3. Configure your MongoDB Atlas connection.
4. Run the application:

python app.py

## Application URLs

Home Page:
http://127.0.0.1:5000/

JSON API:
http://127.0.0.1:5000/api

Success Page:
http://127.0.0.1:5000/success
